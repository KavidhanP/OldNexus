# Branding & UI Rules
- **Primary Color:** #6b0b0c (Deep Burgundy) - Use for Sidebar, Headers, and Primary Buttons.
- **Background:** #f2f7f9 (Cool Frost) - Use for main dashboard canvas.
- **Tech Stack:** Next.js (App Router), TypeScript, Tailwind CSS.
- **UI Style:** Professional, high-contrast, "Glassmorphism" for overlays.
- **Strict Mode:** All TypeScript components must use strict typing. No 'any'.
